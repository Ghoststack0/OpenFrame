OpenFrame · fork of Immich

Immich, reworked for speed and clarity

OpenFrame is an unofficial fork of Immich, the self-hosted photo and video library. It keeps Immich's features, API and app compatibility, and works toward faster uploads and a clearer interface. Most of that is still ahead. This page says plainly which parts are goals and which have shipped.

Goals

These are targets, not features. A goal only moves to shipped with a change you can run, and a speed claim only counts with a before-and-after measurement.

Faster uploadsNot measuredThe web upload panel now shows overall progress (see below). Upload speed itself hasn't changed or been measured end to end.

Outperform current upstream without regressionsPartly measuredThree server changes measured against the fork's base commit. Upload-preflight CPU work is also measured against Immich v3.3.5. Full HTTP upload comparisons are still in progress.

What has shipped

Each change is small and measured on its own, never as a speedup for the whole app.

Two kinds of comparison

OpenFrame reports two kinds of result and keeps them apart, because they answer different questions.

Against the base commitOpenFrame next to the upstream commit it forked from, 256eb55. Shows what each change removed. Against the latest releaseOpenFrame next to Immich v3.3.5. Upload-check method time is 16.5–37.9% lower across nine synthetic workloads. This times one method with an in-memory repository, not end-to-end uploads.

Not end to end

No result here measures a full upload from a phone or browser, network transfer, or the app as a whole. A faster method or query doesn't prove a faster app.

Contribute, with or without AI

Pull requests are welcome, and AI-assisted pull requests are explicitly welcome, for performance, implementations, UX and tests. You stay the author: understand the change, run the checks, and measure any speed claim. See Contributing.

Built on Immich

OpenFrame exists because of the Immich team and its contributors. It uses the same AGPLv3 license and isn't affiliated with or endorsed by FUTO or the Immich team. For installation and the full documentation, use docs.immich.app. Please don't report OpenFrame bugs upstream.
